# Portal Asesmen (Android WebView)

A simple Android Studio project for a WebView wrapper around `https://asesemen-ekamas.carrd.co`.

## Features
- WebView with JavaScript, DOM storage, and cookies enabled.
- Top black rounded toolbar with three decorative symbols (no click actions).
- Clock and battery percentage beside the toolbar.
- Android Back button navigates backward in WebView history.

## Build APK
1. Open this folder in Android Studio.
2. Allow Gradle sync and install Android SDK Platform 35 if prompted.
3. Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. The debug APK will be at `app/build/outputs/apk/debug/app-debug.apk`.
